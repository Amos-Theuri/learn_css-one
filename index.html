Selectors

Used to pick an element to apply a style to

selectors are of different types

  • universal selector

    • Selects all elements in the document *

  • Class selector

    • Class attribute is given to an element then in css a period(.) followed ny a case sensitive name of the class is given

    An element can have multiple class names seperated by space

  • ID selectors

    • ID is a unique name that is assigned to only one element in the document.

    The selector is #

  • Group selector

    • Selects two or more elements with different class names or none at all

    select the elements seperating them with a comma eg h1, h2 { style: apllied;}

  • Chained selectors

    • select a specific element which shares an initial class name as other elemnts but different preceding names

    It will select only that eg .clssnme1.classnm2 { style:applied;}

    Here you may have one or more elements with the class name clssnme1 but only those that also have classnm2 will be selected

  • Descendant selector

    • selects a element in a nested section/ container by following the path specified by either id name or class name, both can be applied at a time

    Different from chained because the names should be seperated by a space eg #parent .child1 .child2

    This will select element class child2 only if it is nested under element class child1 which is nested under element with id parent
